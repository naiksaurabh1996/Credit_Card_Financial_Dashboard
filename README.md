# Credit_Card_Financial_Dashboard
Interactive Power BI dashboard analyzing credit card transactions, customer spending behavior, revenue trends, interest earnings, and transaction patterns. Includes insights by card type, expenditure category, customer demographics, occupation, education, and regional performance using dynamic visualizations and KPI tracking.

# Credit Card Financial Dashboard – Power BI

## Project Overview
This Power BI dashboard analyzes credit card transactions, customer behavior, revenue trends, and expenditure patterns.

## Key Insights
- Total Revenue: 55.3M
- Total Interest Earned: 7.8M
- Transaction Amount: 44.5M
- Total Transaction Count: 656K

## Dashboard Features
- Revenue Analysis by:
  - Card Type
  - Expenditure Type
  - Education
  - Customer Job
  - Age Group
  - Marital Status
  - State
- Quarterly Revenue Trends
- Weekly Revenue Analysis
- Customer Segmentation
- Transaction Mode Analysis (Swipe, Chip, Online)

## Tools Used
- Power BI
- Excel / CSV
- Data Visualization
- DAX
- Data Cleaning
